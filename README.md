# Guild HQ

This is the headquarters of our guild. Everything happens through **Issues**.

> **This repository is public.** Never write your real name, your school, or anything private here.

## Getting started

1. Open [New issue](https://github.com/kwaka1208/guild-hq/issues/new/choose) and choose **Join the Guild**.
2. Wait a few seconds. The guild bot will reply to your issue.
3. Check the [Leaderboard](LEADERBOARD.md).

## Reading: quests

The quests are in [guild-quests](https://github.com/kwaka1208/guild-quests).
Read its README to learn how to **fork** it and get new quests every week.
When you clear a quest, submit the flag here with the **Submit a Flag** form.

## Writing: your team's game

1. The team leader opens [guild-game-template](https://github.com/kwaka1208/guild-game-template)
   and clicks **Use this template**. Make the new repository **public**.
2. The leader invites the other members: **Settings → Collaborators → Add people**.
3. The leader registers the repository with the **Register a Team Repository** form.

## Open source

Our repositories are open source projects. You can contribute to them:

- **guild-quests**: fix typos, broken links, or confusing sentences.
  Start with issues labeled `good first issue`.
- **Other teams' games**: report bugs, and send pull requests.

When you are ready, try a real open source project! Ask the guild master
to review your pull request **before** you send it.

## Points

| Action | Points |
|---|---|
| Clear a quest | 30 |
| First, second, third to clear | +10, +5, +3 |
| Use a hint card | -5 |
| Writing tasks (Issues, PRs, README, ...) | Scored with a rubric |
| Merged pull request to guild-quests or another team's game | 60 |
| Merged pull request to a real open source project | Bonus |

The leaderboard is updated when something happens here, and every hour.
